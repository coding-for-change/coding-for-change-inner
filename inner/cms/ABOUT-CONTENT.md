# About Page — CMS content (copy-paste reference)

Content for the new **About Page** global and its supporting entries. Enter it
by hand in the CMS admin (the global starts empty).

**Where:**
- Page copy → CMS admin → **Globals → About Page**
- Identity FAQ → **Collections → FAQs** (create entries with **Category: About**)
- Stat tiles → **Globals → Site Configuration → About-page stats**

**Localization:** fill in **English** first, then switch the locale selector
(top-right) to **Deutsch** and fill the German values. For array fields (Fact
box, Steps, Media, Get-involved cards) edit the *same rows* after switching
locale — don't add new rows — so EN/DE stay attached to the same entry.

**Rich-text fields** (`Definition`, `People body`, `Funding body`): type the
text normally; **bold** the phrases shown in `**asterisks**` below using the
editor's bold button. `ctaHref`, `url`, and `outlet` are **not** localized.

## After entering the content

- Sections only render once they have content, so the page fills in as you go —
  no half-empty layout while drafting.
- Project cards come from the **Projects** collection automatically; nothing to
  enter here for them.
- The site-wide entity facts (founders, founding date, TUM affiliation, social
  links) live in the `Organization` JSON-LD in `inner/src/app/layout.tsx` — not
  the CMS — so they stay consistent across every page.
